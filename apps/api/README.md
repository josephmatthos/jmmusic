

# JM Music v2

Plataforma proprietária de streaming, assinatura e licenciamento musical.

- Catálogo exclusivo de Joseph Matthos
- Assinatura mensal/anual
- Licença individual por faixa
- Web (Next.js) + Mobile (Expo)
- API NestJS + PostgreSQL + Redis
- Áudio em S3 privado + CloudFront
- Pagamentos via Mercado Pago

Consulte `docs/ARCHITECTURE.md` e `infra/LOCAL_DEVELOPMENT.md`.
